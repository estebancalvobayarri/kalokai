# Kalokai

Web de Kalokai, formación para empresas en salud, negocio y tecnología que empieza por las personas.

## Estructura

- `index.html`: contenido de la página.
- `styles.css`: paleta, tipografía y maquetación.
- `script.js`: cabecera al desplazarse y formulario de contacto.
- `favicon.svg`: icono del sitio (símbolo del logo).

Es una web estática, sin dependencias ni compilación. Para verla en local, abre `index.html` en el navegador.

## Identidad visual

| Nombre | Color | Uso |
| --- | --- | --- |
| Noche | `#0E1726` | Fondo principal |
| Medianoche | `#182540` | Tarjetas y bloques |
| Bruma | `#9AA6B8` | Texto secundario |
| Claro | `#F3F4F7` | Texto principal y secciones claras |
| Ámbar Kalokai | `#FFB224` | Color de marca: botones y detalles |

Tipografías: Bricolage Grotesque para titulares y Figtree para textos.

Logo: la palabra «kalokai» junto al símbolo de la persona que crece (un círculo ámbar sobre un arco abierto).
