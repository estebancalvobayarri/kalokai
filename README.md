# Kalokai

Web de Kalokai, formación para empresas en salud, negocio y tecnología, inspirada en la *kalokagathía* griega.

## Estructura

- `index.html`: contenido de la página.
- `styles.css`: paleta, tipografía y maquetación.
- `script.js`: cabecera al desplazarse y formulario de contacto.
- `favicon.svg`: icono del sitio.

Es una web estática, sin dependencias ni compilación. Para verla en local, abre `index.html` en el navegador.

## Identidad visual

| Uso | Color |
| --- | --- |
| Fondo (mármol) | `#F4F5F2` |
| Texto y bloques oscuros (pizarra) | `#17232F` / `#1D3040` |
| Acento, la «y» (bronce) | `#B5893A` |
| Salud (laurel) | `#4A6B4E` |
| Negocio (granate) | `#6E3B36` |
| Tecnología (egeo) | `#2B6580` |

Tipografías: Newsreader para titulares y textos editoriales, Hanken Grotesk para el resto.
